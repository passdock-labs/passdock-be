# passdock-be

Kotlin Spring Boot MVC API for PassDock.

## Stack
- Kotlin
- Spring Boot MVC
- PostgreSQL schema + Flyway migration
- Kafka dependency
- Prometheus actuator endpoint
- Docker
- GitHub Actions CI

## Resume bullet
- Passkey 로그인 이벤트를 위험 규칙 평가와 알림 상태 API로 분리하고 Kafka/Prometheus 기반 운영 확장 지점을 설계.
